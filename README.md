## 🚀 What is Tron AML Scanner?

**Tron AML Scanner** is a lightweight Windows application designed to check any **Tron (TRX / USDT TRC20)** wallet address for AML (Anti-Money Laundering) risk. It analyzes the address against a set of risk indicators and produces a clear, human-readable report — no blockchain explorer juggling, no manual research, no third-party websites.

Whether you are a trader receiving USDT TRC20 payments, an OTC desk verifying counterparties, a merchant processing TRX, or a compliance officer doing quick due diligence — this tool gives you an instant AML snapshot of any Tron address.

The tool focuses **only on the Tron blockchain**, which allows it to deliver faster, more accurate and more detailed reports than general-purpose multi-chain scanners.

## 🔬 What the AML report includes

Each scan returns a structured AML report with the following sections:

- **AML Risk Score (0–100)** — overall risk level: Low / Medium / High / Critical
- **Sanctions Screening** — checks against global sanctions lists (OFAC, EU, UN, UK)
- **Blacklist Check** — known scam, fraud, and reported addresses
- **Mixer / Tumbler Exposure** — direct and indirect interaction with mixing services
- **Darknet & Illicit Exposure** — indirect links to darknet markets and illicit funds
- **Exchange Interaction** — deposits / withdrawals to major CEX and DEX platforms
- **Counterparty Analysis** — how many risky addresses interacted with the target
- **Transaction Summary** — total received, total sent, current balance, tx count
- **First Seen / Last Seen** — address age and recent activity
- **Detailed Verdict** — plain-language summary of the risk profile
